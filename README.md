## How to run :

- Make sure you have docker and in a post 2024 linux environment

- Run ./build.sh

- If no error appears, run ./simulation.sh

- You can see the visual simulator running on http://localhost (unless modified)

## How to make your own changes :

- Go to `./users/catkin_ws/src/krpc_user/` and make sure it's structure is as such: 

    ``` 
        CMakeLists.txt
        launch
        package.xml
        scripts
        src
    ```
- You may modify ./src as you may.
